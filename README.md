# ClassMate AI v3 — сынып жетекшісінің цифрлық көмекшісі

**Мәртебесі: кеңейтілген жергілікті функционалдық прототип / көрмелік MVP. Мектепке өндірістік енгізуге және ашық интернетке жариялауға дайын, құқықтық тұрғыдан қабылданған өнім емес.**

Бұл жинақ қолданушы берген *ClassMate_AI_Technical_Specification_KZ.docx* құжатына сүйеніп жасалды. 15 модульге арналған интерфейс бар, 12 қабылдау критерийі бөлек бақыланады. Қауіпсіздік, масштабталу, заңдық және интеграциялық талаптардың бірқатары **толық орындалмаған** — қараңыз `ACCEPTANCE.md`.

## Windows-та ашу — 3 қадам

1. ZIP архивінен барлық файлды **Извлечь все** арқылы шығар.
2. Шығарылған папкадан **`START_CLASSMATE_V3.bat`** файлын екі рет бас. Қара терезені жаппа.
3. Chrome-да **http://127.0.0.1:8772/** мекенжайын аш. Бұл — жаңа порт, бұрынғы 8765/8766/8770 нұсқаларымен шатаспайды.

Бірінші кіргенде өз **әкімші** аккаунтыңды аш. Жүйеде ортақ пароль жоқ. Әкімші әр пайдаланушыға бөлек аккаунт жасайды. Уақытша парольді алғашқы кіргенде ауыстыру талап етіледі.

**Python 3.11 немесе жаңарақ қажет.** Басты серверге pip арқылы пакет орнатудың қажеті жоқ. DOCX және HTML/Print PDF экспорттары Python стандартты кітапханасында жұмыс істейді. Дербес PDF генерациясына `reportlab`, ал басқа кеңейтілген экспорттарға `python-docx`, `openpyxl` кітапханалары (егер орнатылған болса) қолданылады. Егер `reportlab` орнатылмаған болса, HTML құжатты ашып, Chrome-да **Басып шығару → PDF ретінде сақтау** пайдалан.

## Көрмеде көрсету реттілігі

1. Әкімші жеке аккаунт ашады, сынып жетекшісі рөлін қосады.
2. Сынып жетекшісі сынып жасап, `EXAMPLE_STUDENTS.csv` файлын «Деректер импорты» бөлімінде **алдын ала қарап → бекітеді**.
3. Пән мұғалімі «Қатысу және үлгерім» бөлімінде «Келмеді» дегенді таңдайды. Жүйе ата-анаға **жіберілмеген** хабарлама жобасын жасайды.
4. Сынып жетекшісі жобаны тексеріп бекітеді. Тек содан кейін ол ата-ананың ішкі кабинетінде көрінеді.
5. «Сынып сағаты» бөлімінде тәрбие сабағын тіркейді; «Тәрбие жоспары» бөлімінде орынбасар бекітуін көреді.
6. «ClassMate көмекшісі» бөлімінде Ollama арқылы ЖИ мәтін жобасын дайындайды; оны педагог өңдеп бекітеді.
7. «Құжаттар және есептер» бөлімінен DOCX/PDF/HTML есеп жүктейді.
8. «Қабылдау критерийлері» бөлімінде орындалған және сыртқы қабылдауды күтетін талаптар көрсетіледі.

## Ollama ЖИ туралы

Платформа бұрыннан орнатылған **Ollama + `qwen3:4b`** моделін `http://127.0.0.1:11434/api/chat` арқылы қолданады. Жаңа модель жүктеу қажет емес. Егер модель ашылмаса, AI бөлігі хабарлама береді, қалған бөлімдер жұмысын жалғастырады. ЖИ-дың қазақша сапасы мінсіз деп кепілдендірілмейді; барлық нәтижелер тек педагог тексеретін **жоба**.

Сезімтал медициналық/психологиялық деректерді AI-ға жіберме. Платформа да мұндай деректерді автоматты түрде Ollama-ға бермейді. Нақты балалардың жеке ақпаратын осы прототипте пайдаланба.

## Негізгі файлдар

- `server.py` — негізгі HTTP сервер, рөлдік ережелер және жаңа модульдер.
- `core.py` — SQLite, логин, қолданыстағы 15 модульдің негізгі API логикасы.
- `index.html` — телефонға бейімделетін интерфейс, қазақша/орысша ауыстырғыш.
- `doc_exports.py` — DOCX, PDF (міндетті емес кітапхана), HTML есептері.
- `tests/test_smoke.py` — 42 автоматты функционалдық тексеру.
- `ACCEPTANCE.md` — FR/NFR/AC сәйкестік картасы.
- `ADMIN_GUIDE.md` — әкімші рөлдері, аудит және резервтік көшірме.
- `API.md` — HTTP API негізгі жолдары.
- `DEPLOYMENT.md` — неге қазір көпшілік интернетке жариялауға болмайды.
- `requirements/ClassMate_AI_Technical_Specification_KZ.docx` — пайдаланушы берген бастапқы техникалық тапсырма.

**Назар аудар:** база `classmate.db` түрінде осы папкаға жасалады, қайта жүктеу кезінде сақталады. Жаңа ZIP ескі базаға автоматты көшірмейді. Егер бұрынғы жазбаларды ауыстыру қажет болса, алдымен олардың демо екенін тексеріп, көшірме алып барып көшіру керек.
